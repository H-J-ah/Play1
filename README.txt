[간식 예산 · 잔여 소주 이월 관리 앱 배포 가이드]

1. 무료 웹 주소 만들기 (Netlify Drop)
   - https://app.netlify.com/drop 에 접속합니다.
   - 이 zip 파일(또는 압축을 푼 폴더)을 화면에 그대로 끌어다 놓습니다.
   - 몇 초 뒤 https://... 형태의 나만의 주소가 생성됩니다. (계속 유지하려면 무료 회원가입 후 Claim)

2. 핸드폰에 앱처럼 바로 설치하기 (아이폰 / 안드로이드 공통)
   - 생성된 주소를 핸드폰 브라우저로 엽니다.
   - 아이폰(Safari): 하단 공유 버튼 -> '홈 화면에 추가'
   - 안드로이드(Chrome): 오른쪽 위 메뉴(⋮) -> '홈 화면에 추가' 또는 '앱 설치'

3. 안드로이드 설치 파일(.apk)로 변환하기 (무료)
   - https://www.pwabuilder.com 에 접속해 1번에서 만든 https:// 주소를 입력합니다.
   - 'Package For Stores' -> Android 선택 후 패키지를 내려받으면 안드로이드용 앱 파일을 얻을 수 있습니다.
